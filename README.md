# موقع خطوتي (Khotwati website) — جاهز لـ Vercel

موقع + سيرفر صغير (دوال Vercel) فيه: الصفحة الرئيسية، التحميل، **الاشتراك بالطلبات** (الكود بيظهر للعميل في الموقع بعد ما تأكد الدفع)، كونسول المالك `/owner`، عربي/English، فاتح/داكن.

## شكل الرحلة
1. العميل يحمّل التطبيق وينسخ **كود الجهاز** ← في الموقع (تبويب اشتراك جديد / تجديد / نقل لجهاز جديد) يلصق الكود ويختار إنستا باي أو فودافون كاش أو أورنج كاش ويحوّل.
2. الموقع بيدّيله **رقم طلب** (`KH-XXXXXXXX`) وصفحة متابعة، وبيجهّز له رسالة واتساب برقم الطلب يبعت عليها إيصال التحويل.
3. إنت تفتح `/owner` وتلاقي الطلب. تتأكد إن الفلوس وصلت وتضغط **✅ تأكيد الدفع وإصدار الكود**.
4. الكود بيتوقّع **جوه متصفحك** بمفتاحك الخاص، وبيترفع للموقع الكود الموقّع بس. صفحة العميل بتتحدّث لوحدها كل ثواني وبيظهر له الكود (مع احتفال 🎉).

**الضمان:** الكود مش موجود على السيرفر قبل ما توقّعه إنت، ومفيش أي طريقة يتعمل من غير مفتاحك الخاص (اللي عمره ما بيتحط على فيرسيل). حتى لو حد اخترق الموقع أو القاعدة مفيش كود يتسرق.
لو السيرفر مش متظبط لسه، الموقع بيرجع تلقائياً للطريقة القديمة (رسالة واتساب فيها كود الجهاز) — فمش هيقع.

## 1) الأرقام والسعر — ملف `site.config.js`
واتساب الطلبات `201508775843` · إنستا باي (حساب + لينك التحويل) · فودافون/أورنج كاش `01225986832` · **السعر 99 جنيه حالياً مثال — غيّره** · بيانات الـAPK · روابط المتاجر (لما تنزل).

## 2) النشر على Vercel
1. ارفع **محتويات** المجلد ده على Repository في GitHub.
2. vercel.com ← Add New ← Project ← اختار الـRepo ← **Framework Preset: Other** ← Deploy (من غير Build Command).

## 3) تشغيل الطلبات (مرة واحدة، حوالي 5 دقايق، مجاني)
1. في مشروعك على فيرسيل: **Storage** ← Create ← **Upstash Redis** (من الـMarketplace) ← وصّله بالمشروع. (بيضيف متغيرات `KV_REST_API_URL` و `KV_REST_API_TOKEN` أو `UPSTASH_REDIS_REST_*` لوحده.)
2. **Settings ← Environment Variables** وأضف:
   | الاسم | القيمة |
   |---|---|
   | `OWNER_TOKEN` | كلمة سر طويلة من عندك (20 حرف+). هي اللي بتدخلها في `/owner` عشان تشوف الطلبات وتؤكدها |
   | `LICENSE_PUBLIC_KEY_HEX` | (موصى بيه) المفتاح العام — بيخلّي السيرفر يتأكد إن الكود موقّع بمفتاحك. المفتاح التجريبي الحالي: `3059301306072a8648ce3d020106082a8648ce3d030107034200042019127a6498498f2a425db3232096da27ba005b2a8ab95fc49036e15ce00b14522a8f29db45f1a04f19b638881d9a9f0caa6c08268cb5aad5dc9b2015ad9291` — ولما تعمل مفتاحك الحقيقي غيّره (ينسخ من `/owner` ← «المفتاح العام») |
   | `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` | (اختياري) بيبعتلك إشعار على تيليجرام أول ما يجي طلب جديد |
3. **Deployments ← Redeploy**.

## 4) الكونسول `/owner`
افتح `موقعك/owner` ← اختار **ملف المفتاح الخاص** + الباسوورد + ملف `licenses.json` + **كلمة سر الطلبات** ← فتح. هتلاقي «📥 طلبات الموقع» فوق قايمة العملاء.
* تأكيد طلب جديد بيعمل العميل في `licenses.json` تلقائياً (رقم الطلب بيتسجل كمرجع دفع)، والتجديد والنقل بيتطبّقوا على ترخيص العميل الموجود.
* لو الجهاز عنده ترخيص نشط بيحذّرك قبل ما تكرر الإصدار.
* **احفظ القاعدة** بعد كل تغيير (كروم/إيدج بيحفظوا في نفس الملف تلقائياً).
* الصفحة ممنوعة تتصل بأي موقع غير موقعك (`connect-src 'self'`)، والمفتاح الخاص بيفضل في ذاكرة التبويب بس.

## أمان الطلبات (باختصار)
حد أقصى للطلبات والمحاولات لكل IP · كلمة سر المالك بتتقارن بأمان وفيه قفل بعد محاولات غلط · الأكواد بتتفحص (لازم تكون لنفس جهاز/ترخيص الطلب وموقّعة بمفتاحك) قبل ما تتحفظ · الطلبات بتتمسح تلقائياً بعد 60 يوم · العميل ما بيشوفش إلا حالة طلبه وكوده.

## تحديث التطبيق
استبدل `downloads/Khotwati-Streaks.apk` وعدّل `apk.version` و`apk.size`. ⚠ الـAPK الحالي مبني بالمفتاح **التجريبي**.

## English (short)
Static site + tiny Vercel serverless API. Edit `site.config.js`, deploy with **Framework: Other**, add an Upstash Redis store and set `OWNER_TOKEN` (+ optionally `LICENSE_PUBLIC_KEY_HEX`, Telegram vars). Customers create an order, you confirm the payment in `/owner` (the code is signed in your browser with your private key and only the signed code is uploaded), and the code appears on the customer's page automatically. Without the backend the site falls back to a WhatsApp message.
